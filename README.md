# Dark_Matter_Halo_Modelling
This project combines both theoretical and applied computation. To establish the theoretical foundation, we will review textbooks and peer reviewed literature on dark matter halos and spiral galaxies. The focus of the study would be around three commonly used density profiles: Uniform, isothermal, and Navarro-Frenk-White (in comparison to the Burkert profile) models . We will then develop computational models of the density profiles using Python and analyze galaxy rotation curve data from the SPARC database.

## Getting Started:
1. Clone the repository.
2. Install the required Python packages.
3. Run main.py to verify the SPARC data loads correctly.
